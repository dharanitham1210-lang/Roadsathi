# Slide 4 – Feasibility and Viability

## Technical Feasibility

- Uses existing GPS, Maps, Cloud and SMS technologies.
- AI fault triage uses a predefined fault knowledge base.
- Offline/SMS fallback supports low-connectivity highways.

## Operational Feasibility

- Connects with existing local garages and spare-parts shops.
- Provides automated mechanic matching.
- Supports parts-aware routing.
- Uses KYC and arrival-code verification for trusted assistance.

## Economic Viability

- No new physical service infrastructure is required.
- Revenue can be generated through per-job commission.
- Fleet subscriptions can provide an additional revenue model.
- Creates additional income opportunities for idle local garages.

## Scalability & Sustainability

- Start with a pilot highway corridor.
- Target approximately 15 km garage coverage.
- Expand to multiple highway corridors.
- Expand to fleets and authorities.
